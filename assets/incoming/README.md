# AI fayllar uchun papka

AI xizmatlarida yaratilgan asl fayllarni shu yerga tashlang. Keyin `npm run assets:import` buyrugʻini ishga tushiring.

Asl fayllar katta boʻlgani uchun GitHub'ga **yuklanmaydi**, faqat shu kompyuterda turadi. Saytga ularning siqilgan nusxalari (`public/media/ai`) chiqadi.

- Har bir faylning aniq nomi va prompti: [docs/AI-PROMPTS.md](../../docs/AI-PROMPTS.md)
- Ish tartibi va qoidalar: [docs/AI-ASSETS.md](../../docs/AI-ASSETS.md)
